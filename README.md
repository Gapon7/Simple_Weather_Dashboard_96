The Simple Weather Dashboard is a responsive web app that provides real-time weather updates based on the user's location. Using the OpenWeather API and the browser’s geolocation services, it displays weather data such as temperature, weather conditions, air quality, and hourly forecasts. The app also shows a 5-day forecast, sunrise and sunset times, and additional environmental data like humidity and wind speed. It includes links to trusted weather news sources. Built with HTML, CSS, JavaScript (React/Angular), and OpenWeather API, the dashboard features a clean, minimal UI and is responsive across desktop and mobile platforms. The project highlights the integration of real-time data and user-focused design.
