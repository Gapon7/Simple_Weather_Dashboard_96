# **App Name**: Clear Sky View

## Core Features:

- City Search: Implement a search bar to allow users to enter a city and retrieve weather information.
- Weather Info Card: Display weather information in a clear, concise card format, including city name, temperature in Celsius, weather condition icon, humidity, wind speed, and Air Quality Index (AQI).
- Dashboard Layout: Develop a single-page layout that is readable and easy to navigate, ensuring all weather information is readily accessible.

## Style Guidelines:

- Primary color: Light blue (#E0F7FA) for a clean and airy feel.
- Secondary color: Gray (#B0BEC5) for text and subtle accents.
- Accent: Teal (#26A69A) for interactive elements and highlights.
- Use a grid-based layout to ensure responsiveness and a structured presentation of information.
- Employ a set of consistent, outline-style weather icons for visual clarity.
- Incorporate subtle transitions and animations when updating weather information.
